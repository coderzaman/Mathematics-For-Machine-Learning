# 📘 Math for Machine Learning & Deep Learning - Personal Notes

This repository contains my personal notes and materials covering fundamental to advanced mathematical concepts required for Machine Learning (ML) and Deep Learning (DL). Each topic includes my custom-made notes, visual explanations (graphs/trees), and Google Colab notebooks (.ipynb).

## 🚀 Course Content (What I've Learned):

**📁 01 & 02: Linear Equations, Scalars, and Vectors**

* Basic concepts of linear equations and the equation of a straight line ($y = mx + c$).
* Understanding Scalars (magnitude only) and Vectors (magnitude and direction).
* How to represent data in vector spaces.

**📁 03: Matrices for ML and DL**

* The application of matrices in Machine Learning.
* Matrix operations for handling multiple variables and features.

**📁 04 & 05: Derivatives From Scratch & Advanced Derivatives**

* Understanding how the rate of change (derivative) works.
* Mathematical calculations for finding slopes.
* The Chain Rule and Partial Derivatives (for multi-variable functions).

**📁 06: Gradient Descent**

* Techniques to minimize the Cost Function (MSE).
* The role of the Learning Rate ($\alpha$) and understanding the "overshooting" problem.
* Multivariate Gradient Descent (visualizing model updates in 3D bowls or hyperplanes).

**📁 07: Statistics Intro (Data Preprocessing)**

* Descriptive vs. Inferential Statistics.
* Central Tendency (Mean, Median, Mode) and the logic behind when to use which.
* The difference between Variance and Standard Deviation.
* Outlier detection (using IQR) and Feature Scaling.

**📁 08: Intro to Probability**

* Basic rules of probability and understanding Sample Spaces.
* Solving complex sequential events using Probability Trees.
* Complement Probability and the Addition Rule (Joint vs. Disjoint events).
* Conditional Probability and its real-world applications in ML (Logistic Regression, Sigmoid function, Naive Bayes).

## 🛠️ Tools & Technologies:

* **Python:** For mathematical implementations.
* **Google Colab:** For writing code and keeping interactive `.ipynb` notes.
* **Custom Visuals:** Hand-drawn and generated diagrams for a better intuition of complex math concepts.
